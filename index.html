1. Configurazione API

Devi inserire solamente il link dell'API e la tua API Key. Non devi conoscere endpoint o parametri tecnici.

Proxy Cloudflare attivo
Le richieste del browser passano attraverso il proxy per evitare problemi CORS. Il proxy non aumenta il numero di richieste consentite dalla tua API.

2. Campionati da analizzare

Seleziona uno o più campionati. Puoi cambiare la selezione in qualsiasi momento.

3. Cosa vuoi verificare?

Puoi selezionare contemporaneamente tutte le informazioni che vuoi testare. Il programma cercherà automaticamente di capire quali dati l'API è in grado di fornire, senza chiederti endpoint manuali.

4. 📚 Verifica dati storici

Puoi controllare automaticamente se l'API dispone di dati delle stagioni passate. Il tester proverà a utilizzare il minor numero possibile di richieste.

5. Avvia test automatico

Il tester proverà automaticamente le richieste più probabili in base alle informazioni selezionate. Non devi scrivere endpoint.
